# 05 · 给 AI 的从零构建指南

> 本文面向 AI 编码助手。目标：让 AI **仅凭本文档**就能从零构建出一个功能等价的「震感音乐」App。
> 建议把本文与 [02-信号处理算法](02-信号处理算法.md) 一起作为上下文提供给 AI。

---

## 0. 任务定义（给 AI 的 prompt 模板）

```
你要开发一个 Android App：震感音乐（包名可自定，示例 com.example.musicvibe）。
功能：捕获系统正在播放的音频，提取低频打击成分，驱动手机马达振动，
      让音乐/影视的低音"震"出来。所有参数可在界面实时调节并立即生效。

技术要求：
- 语言：Java；最低 API 29；目标 API 34
- 音频捕获：MediaProjection + AudioPlaybackCapture，48kHz/16bit/立体声，取右声道
- 无需 root
- 前台服务 + 通知
- 参数用 SharedPreferences 持久化，拖动滑块即时生效（无需保存按钮）
- 严格按 [02-信号处理算法] 的信号链与常数实现

交付：完整的 Gradle 工程，可编译出 release APK。
```

## 2. 分步实现规格

### 步骤 1：AndroidManifest.xml

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PROJECTION" />
    <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

        <activity android:name=".MainActivity" android:exported="true"

        <service android:name=".MusicCaptureService"
```

### 步骤 2：HapticProfile.java

**不可变数据类**，所有字段 `public final`，构造器私有，提供：

1. 全部参数字段（见下表）；
2. 静态默认预设 `MUSIC`；
3. `with(...)` 方法：以当前实例为基底，覆盖任意字段生成新实例（参数为包装类型，`null` 表示不覆盖）；
4. 两个静态常数 `FREQ_ZERO_RATE_REF = 0.25`、`FREQ_SMOOTH = 0.25`。

字段清单（顺序即构造器参数顺序）：

```java
int sourceLowHz, sourceHighHz;         // 谐波源频段
int hapticLowHz, hapticHighHz;         // 触觉带通频段
float hapticGainDb;                    // 触觉增益 dB
float vibeThreshold, envelopeRise, envelopeRelease;
int fallbackLowpassHz, fallbackHighpassHz; float fallbackGainDb;
int hapticCascade;
float energyGain; long pulseMs; boolean followVolume;
```

默认预设（**必须与 [03] 一致**）：

```java
public static final HapticProfile MUSIC = new HapticProfile(
        30, 150, 100, 1150, 12f, 0.50f, 1.00f, 0.50f,
        100, 40, 3f, 1, 40f, 600L, true);
```

### 步骤 3：SoundParams.java

职责：

1. **持久化**：10 个参数的读写（`K_*` 常量）；
2. **默认值迁移**：`DEFAULTS_VER`（当前 **7**），版本不符则 `clear()`；
3. **范围常量**：`GAIN_MIN/MAX`、`THRESHOLD_MIN/MAX`、`BAND_LOW_MIN/MAX`、`BAND_HIGH_MIN/MAX`、`BAND_MIN_GAP`、`ENERGY_GAIN_MIN/MAX`、`PULSE_MIN/MAX`、`SOURCE_LOW_MIN/MAX`、`RISE_MIN/MAX`、`RELEASE_MIN/MAX`（数值见 [03]）；
4. **`save(...)`**：写入时统一 clamp，并保证"频宽下限 + GAP ≤ 上限"；
5. **`build(Context)`**：`HapticProfile.MUSIC.with(全部已保存值)`；
6. **`signature(Context)`**：所有参数拼接成字符串。

> 全部读取方法都要经过 `prefs(c)`，以便触发版本迁移。

### 步骤 4：MusicCaptureService.java（核心）

**常数**（类级 `private static final`）：

```java
double AGC_ATTACK = 0.35;
double AGC_RELEASE = 0.004;
double AMP_GAMMA = 2.2;
double MUSIC_GAIN = 1.2;
```

**内部类 FilterCoeffs**：持有三组 biquad 系数 + 状态，方法：

```java
void rebuild(HapticProfile p)              // = rebuild(p, true)
void rebuild(HapticProfile p, boolean resetState)
```

- `rebuild` 中用 Q=0.70710678、fs=48000 计算低通/高通/低通三组系数（公式见 [02] §2）；
- `resetState == true` 才把滤波器历史清零；**运行时调参必须传 false**。

**采集线程伪代码**（完整版见 [02] §10）：

```
初始化：fc、cur、env=0、agcPeak=0.15、freqSm=0.5
while (running)：
  1. 参数签名变化 → cur = build(); fc.rebuild(cur, false); driver.setProfile(cur)
  2. n = audioRecord.read(buf)
  3. 遍历右声道样本（i 从 1 步进 2）：
       x → 低通 → |.| → 高通 → 低通 → [级联] → b
       统计 b 过零、累加 b²
  4. rms = sqrt(sum/frames)
  5. 包络平滑 → env
  6. AGC → norm
  7. amp = pow(norm, 2.2) × 1.2 × 1000
  8. 过零率 → pulseMs
  9. driver.driveRaw(amp, pulseMs)
```

**服务生命周期**：

- `onCreate`：建通知渠道、建 driver；
- `onStartCommand`：`startForeground()` → 取 Intent 里的授权数据 → `startCapture()`；
- `startCapture`：
  - 检查 `SDK_INT >= Q`；
  - `getMediaProjection(resultCode, resultData)`；
  - 构建 `AudioPlaybackCaptureConfiguration`（加 USAGE_MEDIA/GAME/UNKNOWN）；
  - 构建 48k/16bit/STEREO 的 `AudioFormat` 与 `AudioRecord`（buffer = minBuf）；
  - `chunkFrames = HardwareChunkFrames(minBuf)`，`chunkSamples = chunkFrames*2`；
  - `startRecording()` → `startLoop()`；
- `onDestroy`：按 §5 顺序释放。

### 步骤 5：MusicVibeDriver.java

见 [04] §4 完整代码。要点：

- 构造时获取 Vibrator（API S+ 用 VibratorManager）；
- `setProfile(HapticProfile)` 用 `volatile` 字段；
- `driveRaw(int amp, long pulseOverride)`：
  1. 夹取 amp 到 0..1000；
  2. `threshold = (int)(vibeThreshold*1000)`；
  3. `amp < threshold` → `cancel()` 并 return；
  4. 门槛之上归一化到 0..1000，再映射到 0..255；
  5. `followVolume` 时乘音量比；
  6. 与 `lastAmp` 差 < `AMP_STEP(3)` 则跳过；
  7. `VibrationEffect.createOneShot(pulse, level)`；
- `release()`：cancel + lastAmp=0。

### 步骤 6：MainActivity.java

- `setContentView(R.layout.activity_main)`；
- 用 `registerForActivityResult` 处理 MediaProjection 授权 → `startForegroundService`；
- `setupSliders()`：为 9 个 SeekBar 绑定（范围/初值/回调）+ 1 个 Switch；
- `initializing` 标志位保护初始化；
- 回调里 `persist()` + `updateLabels()`；
- `toSlider/fromSlider` 统一映射（见 [03] §4）；
- API 33+ 请求 `POST_NOTIFICATIONS`。

### 步骤 7：布局与资源

`activity_main.xml`：`ScrollView > LinearLayout(vertical)`，依此排列：

```
标题 / 说明 / [开启按钮] / [停止按钮] / 状态文本
/ 参数标题 / 参数提示
/ (标签+SeekBar) × 9
/ (Switch 跟随音量)
```

9 个参数顺序：强度、门槛、低频下潜、响应上升、响应下降、频宽下限、频宽上限、总增益、振动时程。

## 3. 验收测试清单（给 AI 自测）

实现完成后，逐项确认：

- [ ] 能编译出 release APK，安装成功；
- [ ] 点击"开启"会弹出屏幕录制授权，文案说明用途；
- [ ] 授权后播放音乐，手机开始随鼓点振动；
- [ ] 播放安静的段落，**没有持续的背景震动**；
- [ ] 不同音量的歌都能震（AGC 生效）；
- [ ] 拖动门槛/gamma 相关滑块，效果**立即**变化（无需重启）；
- [ ] 拖动滑块时不会出现"完全不震动"（滤波器状态未被复位）；
- [ ] 点击"停止"后振动立即结束，通知消失；
- [ ] 系统音量调到 0 且"跟随音量"开启时，不振动。

## 4. 常见错误（AI 必须避免）

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 参数变化时 `fc.rebuild(cur, true)` | **完全不震动** | 运行时传 `false` |
| gamma 用 < 1 的指数 | 背景乱震 | 用 > 1（默认 2.2） |
| 服务内 `if (amp > 1000) amp = 1000` 截断 | 饱和+断续 | 服务不截断，驱动统一夹取 |
| 采集缓冲用 `minBuf × 2` | 延迟高、与画面脱节 | 用 `minBuf × 1` |
| 读取块用 2048 帧 | 延迟约 43ms | 用 480 帧（10ms） |
| 脉宽小于块长 | 振动断续"哒哒" | 脉宽下限 = 块长 |
| 忘记 `DEFAULTS_VER` +1 | 新默认值不生效 | 改默认值就 +1 |
| 初始化不设 `initializing` | 覆盖用户已存设置 | 初始化期间忽略回调 |
| 不调 `startForeground` | 后台被杀 | 立即提升前台 |

## 5. 可直接复用的代码骨架

以下是 AI 需要**逐字实现**的关键片段（其余按本文档推导）：

**包络 + AGC + gamma + 脉宽（采集线程每块）**

```java
// 包络平滑
float target = (float) rms;
env += (target - env) * (target > env ? cur.envelopeRise : cur.envelopeRelease);

// AGC
agcPeak += (env - agcPeak) * (env > agcPeak ? AGC_ATTACK : AGC_RELEASE);
if (agcPeak < 1e-4) agcPeak = 1e-4;
double norm = Math.max(0.0, Math.min(1.0, env / agcPeak));

// gamma + 增益（不截断）
int amp = (int) (Math.pow(norm, AMP_GAMMA) * MUSIC_GAIN * 1000);
if (amp < 0) amp = 0;

// 频率 → 脉宽
freqSm += (normFreq - freqSm) * HapticProfile.FREQ_SMOOTH;
freqSm = Math.max(0.0, Math.min(1.0, freqSm));
long pulseMax = cur.pulseMs;
long pulseMin = Math.max(8L, pulseMax / 6L);
long blockMsFloor = Math.max(20L, frames * 2L * 1000L / 48000L);
long pulseMs = (long) (pulseMax - (pulseMax - pulseMin) * freqSm);
if (pulseMs < blockMsFloor) pulseMs = blockMsFloor;

driver.driveRaw(amp, pulseMs);
```

**参数变更检测（采集线程每块开头）**

```java
String newSig = SoundParams.signature(this);
if (!newSig.equals(sig)) {
    sig = newSig;
    cur = SoundParams.build(this);
    fc.rebuild(cur, false);      // 关键：不复位状态
    driver.setProfile(cur);
}
```
