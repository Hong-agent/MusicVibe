# 震感音乐 MusicVibe · 开源技术文档

> 让手机的马达，随着系统播放的音乐一起"呼吸"。

## 这是什么

**震感音乐（MusicVibe）** 是一个 Android 应用概念与算法实现：它**不需要修改任何音乐 App**，而是通过系统级音频回环捕获（AudioPlaybackCapture）实时"听"到手机正在播放的声音，提取其中的低频打击成分，转成 X 轴线性马达（LRA）的振动幅度与节奏，让**整个机身、甚至它压着的桌面**都跟着音乐一起震。

它不是简单的"振幅跟随"，而是一套完整的**音频 → 触觉**信号处理链：

```
系统音频 → 谐波提取 → 打击包络 → 自适应增益 → 伽马整形 → 振幅
                     ↘ 过零率 → 脉宽映射（频率感）
```

## 核心理念：为系统影音引入新的触觉体验

过去，手机的触觉只服务于「通知」「按键」这类离散事件——短促、孤立、与内容无关。而影视与音乐里**最抓人的部分是低频打击**：鼓点、爆炸、Bass Drop。这些信息在手机扬声器上往往被削掉（小喇叭放不出 60Hz 以下），却在触觉上完全可以被"还原"出来。

> **触觉是听觉的低频补充通道。**

本项目尝试做的事情，就是把这句假设工程化：

1. **听见低音**——哪怕喇叭放不出来，马达能"震"出来；
2. **震在点上**——只在真正的打击处触发，不产生"无用的背景震动"；
3. **有强有弱**——响的鼓点震得重，轻的过渡震得轻，形成动态而非恒定嗡鸣；
4. **跟得上拍**——端到端延迟压到几十毫秒级别，振动与画面/听感同步。

这套体验是**设备无关**的：只要手机有可调振幅的线性马达，任何正在播放的影视/音乐（Spotify、YouTube、本地播放器……）都能立刻获得这层新的触觉维度，**无需 App 方做任何适配**。

## 一句话开始

如果你只读一段：

> 用 `MediaProjection` + `AudioPlaybackCaptureConfiguration` 拿到系统音频（无需 root），
> 取**右声道** → 低通 150Hz → **全波整流**（制造 2 次谐波，把听不到的低音搬到马达能响的频段）→ 带通 100~1150Hz → RMS 包络 → **AGC 自适应归一化** → **gamma 整形** → 映射成马达振幅；
> 同时用**过零率**估计信号频率高低，映射成振动**脉宽**，让低频"嗡"、高频"哒"。
